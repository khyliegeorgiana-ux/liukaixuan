# 刘凯旋作品集页面设计

## 目标

为现有个人网站新增独立作品集页面，用于向招聘方展示刘凯旋的电商视觉与 AI 视频作品。页面延续首页和简历页的淡蓝、白色、高级简洁视觉体系，并使用内容充实但层次清楚的影院展示式布局。

首版接入五个真实视频作品：一个 16:9 横屏主作品和四个 9:16 竖屏作品。用户点击作品封面后，视频直接在原卡片内播放，不进入详情页。

## 导航与分类

顶部复用现有三项胶囊导航：首页、简历、作品集。作品集入口使用淡蓝色选中状态，左侧继续只显示圆形抽象标志，不显示姓名。

作品集包含两个带线性图标的分类按钮：

1. 电商设计图
2. AI 视频

首版默认选中“AI 视频”，展示五个真实视频。“电商设计图”保留可扩展入口，当前显示与整体风格一致的“作品整理中”状态，不伪造作品。切换分类时不刷新页面，并同步更新按钮的可访问状态。

## 页面布局

采用已确认的 B 影院展示式：

- 标题区展示“作品集”、简短创作说明和两个分类按钮，并使用浅蓝网格、柔和光晕和细线装饰增加层次。
- 16:9 横屏主作品占据第一行主要视觉区域，桌面端同时展示较完整的标题、说明、标签、比例和时长。
- 四个 9:16 竖屏作品在桌面端排列为一行四列，每张卡片显示封面、播放按钮、标题、比例和时长。
- 手机端按主作品、四个竖屏作品的顺序改为单列，保持原始视频比例且不产生横向滚动。
- 页面底部使用简洁的创作说明和现有页脚导航收尾。

## 作品内容与顺序

### 主作品

- 文件：`耳机.mp4`
- 分辨率：1920×1080
- 比例：16:9
- 时长：约 16 秒
- 标题：沉浸式耳机产品视觉

### 竖屏作品

1. `清洁布.mp4`｜480×854｜约 18 秒｜汽车玻璃清洁布演示
2. `制冰盒1.mp4`｜720×1280｜约 8 秒｜便携制冰盒产品短片
3. `收纳盒.mp4`｜480×854｜约 15 秒｜帽子收纳盒场景展示
4. `衣服.mp4`｜480×854｜15 秒｜都市休闲穿搭短片

封面从各自视频中选择清晰、有代表性的画面生成，并单独压缩为网页图片。所有封面均为用户视频的真实帧，不使用虚构项目图。

## 播放交互

- 初始状态显示封面、居中的播放按钮、作品标题、视频比例和时长。
- 点击封面或播放按钮后，视频在原卡片中开始播放，并显示浏览器原生进度、音量和全屏控制。
- 页面不自动播放视频，也不在用户操作前发声。
- 同一时间只播放一个作品；开始播放新作品时，其他正在播放的视频自动暂停。
- 视频使用 `preload="metadata"`，避免页面打开时一次性下载约 78 MB 的全部视频。
- 关闭 JavaScript 时，原生视频控件仍可用于播放；JavaScript 只增强封面切换、单视频播放和分类切换。
- 键盘用户可以操作分类按钮和播放按钮；焦点状态清晰可见。
- 系统启用减少动态效果时，禁用非必要的卡片淡入与位移动画。

## 素材与技术结构

新增 `portfolio.html`，复用现有 `styles.css` 和 `script.js`。视频与封面放入独立的作品素材目录，文件名使用稳定的英文短名，避免部署路径中的编码问题。

页面保持无后端、无第三方运行时依赖，继续适配 GitHub Pages。视频卡片使用一致的 HTML 结构和数据属性，使后续新增、删除或替换作品时不需要改写播放逻辑。

## 响应式与性能

- 桌面端主作品突出，四个竖屏作品一行排列。
- 中等屏幕下竖屏作品变为两列。
- 手机端所有作品单列，播放控件和文字保持可读，点击目标不小于 44 像素。
- 视频不自动预载完整文件，封面使用适合网页的尺寸和压缩质量。
- 页面需避免布局跳动，视频与封面容器预先声明 16:9 或 9:16 比例。

## 验证标准

- 页面包含且只包含“首页 / 简历 / 作品集”三项顶部导航，作品集为当前页。
- “电商设计图 / AI 视频”两个分类按钮均可操作，默认显示 AI 视频。
- 五个视频文件均使用正确标题、比例、时长和展示顺序。
- 点击任一作品可在原卡片内播放；切换作品时前一个自动暂停。
- 不自动播放、不预载完整视频，原生控制可用。
- 无 JavaScript 时，五个视频仍可通过原生控件播放。
- 桌面、平板和手机宽度下无横向滚动，卡片比例正确。
- 页面只使用用户提供的真实视频和视频帧封面，不伪造作品。
- 首页、简历和作品集之间的导航链接全部有效。
- 自动化测试、浏览器烟雾检查和真实视频请求检查通过后，同步发布到 `main` 与 `gh-pages`。
