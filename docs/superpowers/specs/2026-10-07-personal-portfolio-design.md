# 刘凯旋个人简历与作品集网站设计

## 目标

为刘凯旋制作一个公开访问的个人网站，用于求职、个人简历展示和作品展示。职业定位为“AI 美工 / 视频剪辑师”。网站需要在电脑和手机上清晰易用，整体呈现淡蓝、白色、简洁且有层次的高级视觉效果。

## 页面结构

网站包含四个主页面：

1. 首页：个人定位、核心能力、精选作品与主要行动按钮。
2. 关于我：个人介绍、创作理念、擅长方向和工作方式。
3. 简历：技能、经历、教育信息、求职状态和联系方式。公开邮箱为 `2119861292@qq.com`，手机号保留可替换占位。
4. 作品集：按“AI 美工”和“视频剪辑”分类展示作品。每个项目可进入独立详情页。

作品详情页包含项目背景、创作过程、所用工具、成果展示、上一个和下一个作品，以及返回作品集按钮。正式作品由用户后续上传，首版使用容易替换的精致占位内容。

## 导航

所有主页面使用一致的顶部导航。左侧使用简洁的淡蓝色抽象圆形标志，不展示姓名；右侧提供首页、关于我、简历和作品集入口。移动端使用折叠菜单。页面底部提供辅助导航和联系方式入口。

## 首页设计

首页首屏左侧展示“刘凯旋”“AI 美工 / 视频剪辑师”和简短职业介绍，并提供“查看我的作品”和“查看个人简历”按钮。右侧使用淡蓝色抽象视觉作为个人照片或代表作品的临时位置。

首屏之后依次展示：

- AI 视觉创作与视频剪辑两项核心能力；
- 三个精选作品卡片；
- 跳转到简历页联系方式区域的合作邀请。

## 视觉风格

主色采用低饱和淡蓝，搭配暖白背景和深灰文字。页面保留呼吸感，但不会出现大片无内容区域。内容区使用浅蓝渐变、细线网格、半透明光晕、圆角卡片、细边框、小型标签和局部编号增加视觉密度。

装饰元素服务于内容层级，不使用夸张效果。阴影轻柔，圆角统一，字体大小形成清楚的阅读节奏。动效限于淡入、轻微位移、按钮和卡片悬停，以及移动菜单过渡，并支持减少动态效果的系统设置。

## 技术方案

首版采用无后端的静态多页面网站，使用 HTML、CSS 和少量 JavaScript。该方案加载快、维护简单，适合部署到 GitHub Pages 等公共静态托管平台。页面共享统一样式和交互脚本，作品数据结构保持简单，方便后续替换图片、视频和文字。

## 响应式与可访问性

桌面端采用有层次的双栏与卡片网格，手机端自动变为单栏。所有按钮和链接支持键盘操作，图片提供替代文字，颜色保持足够对比度，表单或交互状态使用可读提示。

## 验证

开发完成后检查所有页面与按钮跳转、移动菜单、作品分类、作品详情导航和邮件链接。使用本地静态服务器验证页面加载，并检查常见桌面与手机宽度下的布局。部署前确认没有无效链接和意外的横向滚动。

## 开发顺序

按用户要求逐页完成并审阅：首页、关于我、简历、作品集与作品详情。首页先完成，用户查看后再根据反馈微调，之后沿用确认后的视觉系统制作其余页面。
